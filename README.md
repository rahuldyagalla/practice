# Varsha IT Solutions website (Astro)

    npm install
    npm run dev       # http://localhost:4321
    npm run build     # outputs ./dist

Edit phone, email, WhatsApp and form key in src/data/site.json.
Edit services in src/data/services.json, plans in src/data/packages.json.
Contact form uses Web3Forms: get a free access key at web3forms.com.
Deploy dist/ on Cloudflare Pages or Netlify.
